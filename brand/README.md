# MaizeKit brand

<img src="maizekit-icon-256.png" width="128" alt="MaizeKit icon">

| File | Use |
|---|---|
| `maizekit-icon.svg` | App icon, any size. Org avatar, app tiles, 64 px and up. |
| `maizekit-icon-{1024,512,256,128}.png` | Same icon as PNG. |
| `maizekit-favicon.svg`, `maizekit-favicon-{32,16}.png` | Simplified icon for browser tabs and anything under 64 px. |
| `maizekit-lockup.png` | Icon + wordmark, light and dark. |
| `badge/built-with-maizekit.svg` | README badge (see below). |

## Colour and type

**Colour:** tile gradient `#FFE173` → `#FBB024` → `#EE7C0E`. Symbol is white glass.

**Wordmark:** "MaizeKit", one word, capital M and K, set in the system UI font
(SF Pro on Apple devices). `lockup.html` renders it.
